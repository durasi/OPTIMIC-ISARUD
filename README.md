WordPress sitelerini kademeli olarak optimize etmek için kapsamlı araçlar sunar.

### Açıklama

Optimic ISARUD, web sitenizin performansını artırmak için tasarlanmış kapsamlı bir WordPress optimizasyon eklentisidir. İçerdiği özellikler:

*   Gelişmiş seçeneklerle CSS ve JavaScript dosyalarını küçültme
*   Daha iyi sıkıştırma ve yükleme hızları için JPG ve PNG resimlerini WEBP formatına dönüştürme
*   Çeşitli seçeneklerle CSS küçültme üzerinde detaylı kontrol imkanı

### Kurulum

1.  `optimic-isarud` klasörünü `/wp-content/plugins/` dizinine yükleyin veya WordPress eklenti ekranı üzerinden doğrudan eklentiyi kurun.
2.  WordPress'teki 'Eklentiler' ekranından eklentiyi etkinleştirin.
3.  'Ayarlar' menüsü altındaki "Optimic ISARUD" ayarlar sayfası aracılığıyla ayarları yapılandırın.

### Sıkça Sorulan Sorular

= Optimic ISARUD ne yapar? =

Optimic ISARUD, CSS ve JavaScript'i küçülterek ve resimleri daha verimli WEBP formatına dönüştürerek WordPress sitenizi optimize eder. CSS küçültme sürecini kontrol etmek için çeşitli seçenekler sunar.

= Neden WEBP resimleri kullanılmalı? =

WEBP resimleri, geleneksel JPG ve PNG formatlarına kıyasla üstün sıkıştırma ve kalite sunar, bu da daha hızlı yükleme süreleri ve iyileştirilmiş kullanıcı deneyimi sağlar.

### Description

Optimic ISARUD is a comprehensive WordPress optimization plugin designed to enhance your website's performance. It includes features for:

*   Minifying CSS and JavaScript files with advanced options
*   Converting JPG and PNG images to WEBP format for better compression and loading speeds
*   Detailed control over CSS minification with various options

### Installation

1.  Upload the `optimic-isarud` folder to the `/wp-content/plugins/` directory, or install the plugin through the WordPress plugins screen directly.
2.  Activate the plugin through the 'Plugins' screen in WordPress.
3.  Configure settings through the "Optimic ISARUD" settings page under the "Settings" menu.

### Frequently Asked Questions

= What does Optimic ISARUD do? =

Optimic ISARUD optimizes your WordPress site by minifying CSS and JavaScript, and converting images to the more efficient WEBP format. It offers various options to control the CSS minification process.

= Why use WEBP images? =

WEBP images offer superior compression and quality compared to traditional formats like JPG and PNG, resulting in faster load times and improved user experience.
